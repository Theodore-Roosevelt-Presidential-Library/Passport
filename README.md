# T.R. Passport

A digital passport from the Theodore Roosevelt Presidential Library. Visitors collect a stamp and a photo at each national park, monument and historic site tied to Theodore Roosevelt, modeled on the National Park Service Passport book: region pages, an illustrated sticker for every site, and a round rubber-stamp cancellation with the visit date.

**Live:** https://passport.labs.trlibrary.com (GitHub Pages, `CNAME` in this repo)

**Status:** prototype. All data stays in the visitor's browser. Where data collection will live is still to be decided (see below).

**Coverage:** every unit of the National Park System (475 entries), built from the Library's [Public Lands Directory](https://directory.labs.trlibrary.com). National parks and T.R.-connected sites have illustrated stickers; other units use a duotone badge made from their public-domain NPS photo until they get art.

## What it does

- **Cover and ID page.** Issue a passport with a name and hometown; the ID page carries a passport number and a machine-readable-zone line.
- **Passport book.** Sites grouped by NPS Passport region. Uncollected sites show a faded sticker in a dashed ring; collected sites show the full-color sticker with an inked cancellation.
- **Get your stamp.** Three steps:
  1. **Check in** with the phone's GPS against the site's boundary polygon from the directory (1 km buffer for entrance roads and lots; falls back to the bounding box). Or choose **I visited on an earlier date** to log a past trip.
  2. **Add a photo**: take one or choose from the photo library.
  3. **Stamp** with animation. New achievements show here. Repeat visits add more cancellations.
- **Passport photo** for the holder on the ID page.
- **Live site details** from the directory on each site page: alerts, NPS photo, summary, protection date, acreage, visitors, entrance fee, trails.
- **Stats:** overview tiles, progress by type and region, a state tile map, 29 achievements, and a timeline.
- **Share** a stamp from the stamp screen, the site page or the journal, or share the whole passport from the book. Uses the phone's share sheet; cards are rendered ahead so the sheet opens on the tap.
- **Add to Home Screen** prompt (Android install button, iPhone instructions).
- **Journal.** Every visit with its stamp and photos.
- **Share card.** 1080×1350 PNG with the photo, sticker and cancellation, through the phone share sheet or as a download.
- **Offline.** A service worker caches the app for parks with no signal.
- **Prototype settings** (About tab): simulate location, download data as JSON, reset.

## Data

`data/sites.json` is generated, don't edit it by hand:

```
python3 -m venv .venv && source .venv/bin/activate && pip install pillow
python3 tools/build_sites.py --badges     # pulls directory.labs.trlibrary.com/api/directory.json
```

- `data/curated.json` overrides directory fields per unit (place label, hand-written T.R. line).
- T.R. lines for other units come from the directory's HistorianPanel-reviewed connections.
- New art: add a scene to `tools/scenes.json`, generate with the prompt in `docs/stickers.md`, then `python3 tools/sticker.py <id> <image-url>` and rebuild.
- `agency` is there so the book can grow past NPS (USFS, FWS, BLM, state parks); the directory already has them.

## Data collection: options for later

`js/store.js` is the only file that touches storage. Replace it with an API client when the home is chosen. A visit record looks like:

```json
{ "id": "…", "siteId": "thro", "date": "2026-11-21T21:50:00Z", "verified": "gps", "distanceKm": 0.4, "photoIds": ["…"] }
```

Options to weigh: Supabase or Firebase (accounts + photo storage), a small Cloudflare Worker + R2, or tying passports to ACME/Constant Contact contacts for marketing follow-up.
